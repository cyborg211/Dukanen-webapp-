# Dukanen Brand System

This branch uses the approved Dukanen Marketplace identity as the production design source of truth.

## Core palette
- Primary — Dukanen Green: `#00A86B`
- Deep Green: `#087443`
- Charcoal: `#17221D`
- Off White: `#F8FAF8`
- Gold Accent: `#F4B942`

## Brand principles
- Preserve the approved Dukanen storefront mark and wordmark proportions.
- Do not replace the logo with generic store icons.
- Use a white/off-white surface around the master logo so the approved raster artwork remains visually exact.
- Primary actions use Dukanen Green.
- Deep Green is reserved for stronger brand surfaces and emphasis.
- Gold is an accent, not a primary action color.
- Charcoal is the default text color.
- Mobile-first layouts should use generous touch targets, simple hierarchy, and high contrast.

## Typography
Use `Inter` for Latin text and `Noto Sans Arabic` for Arabic text, with system sans-serif fallbacks.

## UI geometry
- Standard card radius: 18px
- Compact control radius: 12px
- Pill radius: 999px
- Strong but restrained shadows only on elevated cards and primary actions.

## Accessibility
- Maintain visible keyboard focus states.
- Minimum interactive target: 44px where practical.
- RTL layouts must preserve semantic order and icon direction.
